# CardioPatch — 웨어러블 ECG 패치 기반 실시간 AI 부정맥 진단 시스템

웨어러블 ECG 패치 프로젝트(ECG.pptx)의 **투자자·경영진 브리핑용 웹사이트**입니다.
원본 발표자료의 3단계 개발 로드맵을 그대로 살리고, 여기에 **브라우저에서 실제로 동작하는
신호처리 · QRS 검출 · 부정맥 분류 시뮬레이터**를 더했습니다.

> ⚠️ **중요 — 의료기기 아님**
> 모든 심전도 파형은 브라우저에서 **합성한 시뮬레이션 신호**입니다. 실제 환자의 심전도를
> 측정·진단하지 않으며, 의료기기 인허가(식약처 · FDA) 전에는 임상 판단에 사용할 수 없습니다.
> 표시된 성능 수치는 **목표값(target)**이며 임상 결과가 아닙니다.

### 원본 발표자료 반영 내용
- **1단계** 하드웨어 요구사항 및 센서 선정 — TI ADS1298, nRF52840 BLE SoC, 24-bit ADC, 500Hz 이상 샘플링, 3.7V/100mAh 박막 배터리(7일 연속 작동), 50×50mm·2mm 이하 폼팩터 (TI ADS1298, nRF52840 등 선정 부품)
- **2단계** ECG 신호 전처리·특징 추출 — 60Hz 노치, 0.5–100Hz 대역통과, 베이스라인 드리프트 제거, P-QRS-T 분석, RR 간격 변동성(HRV), QT 간격·ST 편차, Pan-Tompkins QRS 검출, 웨이블릿 특징 추출, Python(SciPy·NumPy) → 임베디드 C
- **3단계** AI 부정맥 분류·위험 예측 — 정상 리듬 / 심방세동(AFib) / 심실조기수축(PVC) / 심실빈맥(VT) / 서맥(Bradycardia), MIT-BIH Arrhythmia DB(48시간·47명), PhysioNet, 위험 점수 0–100, **민감도 95%** 목표

## 2. 파일 구조

```
index.html            브리핑 메인 페이지 (히어로·로드맵·사양·파형 라이브러리·차트·미니 데모·FAQ·문의)
demo.html             전체 화면 실시간 ECG 모니터 페이지
css/
  style.css           디자인 시스템 (토큰·컴포넌트·반응형) 19개 섹션
  demo.css            라이브 모니터 전용 스타일
js/
  ecg.js              ECG 파형 합성 · 필터 · 리듬 엔진 · 분류기 (순수 계산 모듈, UI 없음)
  monitor.js          실시간 모니터 엔진 (QRS 검출기 · 캔버스 스트립 · EcgMonitor 컨트롤러)
  charts.js           자체 구현 Canvas 차트 (라인/막대, CDN 비의존)
  main.js             index.html 인터랙션 + 문의 폼
  demo.js             demo.html 컨트롤러
```

### 모듈 의존 관계
```
ecg.js  ←  monitor.js  ←  main.js
   ↑          (QRS검출·렌더링)    ↑
   └──────────────────────────────┴─  demo.js
charts.js ──→ main.js
```
`ecg.js`는 DOM을 전혀 건드리지 않는 순수 계산 모듈이라 재사용·테스트가 쉽습니다.

### 라이브 모니터 페이지 (`demo.html`)
- **2채널 스트립**: 필터링된 ECG + 원시 ADC 파형 동시 표시 (ECG 그리드 포함)
- **실시간 지표**: HR, RMSSD, SDNN, pNN50, 신호품질(SQI), 위험 점수(0–100), 심각도 등급
- **6개 리듬 시나리오**: 정상 / 서맥 / 동성빈맥 / 심방세동 / 심실조기수축 / 심실빈맥
- **신호 조건 제어**: 60Hz 전원 잡음, 필터 체인 on/off, 운동 아티팩트, 표시 속도(8–50 mm/s), 신호 증폭(0.4–2.4×), 노치 주파수(50–60Hz)
- **검출기 상태**: 적응형 임계값, RR 버퍼 사용량, QRS 폭 지수, 판정 신뢰도 미터
- **이벤트 로그 / 판정 타임라인**: 심각도별 색상 구분, 최대 45·30건 유지
- **세션 요약**: 누적 심박, 평균 HR, 평균 RMSSD, 경고·응급 횟수
- **일시정지 / 초기화 / 파형 캡처(PNG)**
- **파이프라인 상세 표**: 화면에서 실제로 도는 8단계 연산 명세

### 실제로 동작하는 신호처리 (표시용 그래프 아님)
1. **합성 심박 생성** — P-QRS-T 형태학을 가우시안 버스트 조합으로 생성 (500Hz)
2. **잡음 주입** — 백색·핑크 노이즈, 60Hz 사인, 기저선 동요(0.24/0.37Hz), 간헐 운동 아티팩트
3. **60Hz 노치 필터** — RBJ biquad, Q=20
4. **0.5Hz 하이패스** — 기저선 드리프트 제거
5. **40Hz 로우패스** — 근전도성 고주파 제거
6. **QRS 검출** — 미분 → 제곱 → 150ms 이동창 적분 → 적응형 임계값 → 200ms 불응기
7. **특징 추출** — RR 평균 · SDNN · RMSSD · pNN50 · 변동계수(CV) · QRS 폭 지수
8. **규칙 기반 분류** — 6개 리듬 판정 + 신뢰도 산출

## 6. 아직 구현되지 않은 기능

### 의도적으로 제외 (정적 사이트 한계)
- **실제 ECG 하드웨어 연동** — BLE 5.0 / NB-IoT 로 패치에서 신호를 받아오는 기능. Web Bluetooth API로 일부 가능하나 실제 기기와 페어링 규격이 필요합니다.
- **서버측 신호처리·파일 변환** — 대용량 심전도 원시 파일의 서버 저장·변환·다운로드 생성
- **실제 ML 모델 추론** — TensorFlow.js 로딩으로 브라우저 내 실추론이 가능하지만, 학습된 가중치 파일과 별도 검증이 필요합니다. 현재는 규칙 기반 분류기입니다.
- **의료기기 인증 기능** — 사용자 인증·세션·접근 제어(민감 의료 데이터 보호)

### 개선 여지가 있는 부분
- 관리자용 문의 대시보드(삭제·상태 변경) 미구현
- 리듬 전환 시 분류기 재학습 구간이 있어 판정까지 약 2~3초 소요
- **서맥(Bradycardia) 오분류 잔존** — 아래 "알려진 한계" 참조

## 7. 알려진 한계 (검증 결과 기반)

개발 중 자체 테스트로 다음을 확인했습니다.

**수정 완료**
- 정상 리듬에서 R파가 누락되어 12초에 2박동만 검출되던 문제 → 리듬 엔진이 고정 배열 인덱스 대신 시간 기준으로 겹치는 심박을 순회하도록 재작성
- `.reveal` 등장 애니메이션 요소가 동적으로 생성되어 영구히 투명하게 남던 문제 → 옵저버 등록 순서 조정
- Chart.js CDN 차단 시 AI 성능 차트가 빈 영역으로 남던 문제 → 외부 의존성 없는 자체 Canvas 차트로 교체

**잔존 (검증 시 6개 리듬 중 4개 정확 분류)**
- **서맥**: 느린 심박에서 T파가 R파로 오검출되어 거짓 짧은 RR이 생기고, 이를 조기박동으로 해석해 PVC로 오분류될 수 있습니다. 검출 임계값을 올려 완화했으나 완전 해결에는 심박별 T파 억제 구간(blanking window) 구현이 필요합니다.
- **심방세동**: AR(1) 스무딩이 RR 변이를 억제해 변이 지표가 낮게 측정되면 동성빈맥으로 오분류될 수 있습니다. 스무딩 가중치를 변이 크기에 따라 조정했으나 추가 튜닝이 필요합니다.

이는 임상 알고리즘이 아닌 **데모용 규칙 기반 분류기의 본질적 한계**이며, 사이트에도 시뮬레이션임을 명시하고 있습니다.

## 8. 다음 개발 단계 제안

1. **분류기 정확도 개선** — 서맥/심방세동 오분류 해결
   - QRS 검출기에 T파 억제 구간(blanking) 및 Pan-Tompkins 원본의 2단계 임계값(THR1/THR2) 적용
   - 분류를 규칙 기반에서 템플릿 매칭 또는 소형 신경망으로 전환
2. **Web Bluetooth 연동 실험** — 실제 ECG 패치와 페어링해 라이브 스트림 수신
3. **리듬 스트레스 테스트** — 리듬 전환·잡음 극한 조건에서 검출기 강건성 자동 측정
4. **관리자 대시보드** — 문의 관리(상태·담당자·삭제) 및 CSV 내보내기
5. **접근성·성능 마감** — 스크린리더 전용 파형 요약 텍스트, 캔버스 렌더링 오프로드(OffscreenCanvas)
6. **다국어(영문) 지원** — 해외 투자자 브리핑용
